# 🚀 HTML5 Moderno: Del Cero al Profesional

## Enfoque práctico, humano y orientado a la vida real

> Un temario diseñado para niños, jóvenes y adultos mayores que desean aprender desarrollo frontend sin sentirse abrumados.

---

# 🎯 Objetivos del Curso

Al finalizar el curso, el estudiante podrá:

- Comprender cómo funciona una página web.
    
- Crear páginas HTML modernas y semánticas.
    
- Construir sitios accesibles y optimizados.
    
- Entender las bases reales del frontend.
    
- Aplicar buenas prácticas profesionales.
    
- Publicar proyectos reales en Internet.
    
- Aprender sin necesidad de memorizar cientos de etiquetas.
    

---

# 🧠 Filosofía del Curso

Este curso NO busca:

- memorizar etiquetas,
    
- aprender teoría infinita,
    
- ni convertirse en una enciclopedia de HTML.
    

Este curso SÍ busca:

- aprender haciendo,
    
- entender cómo funciona la web,
    
- construir proyectos reales,
    
- desarrollar lógica visual,
    
- crear sitios modernos,
    
- y perder el miedo al código.
