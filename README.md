## 📖 ¿De qué trata este curso?

Este no es otro curso que te hace memorizar cientos de etiquetas. Aquí aprendes **haciendo**: entiendes cómo viaja una página por Internet, construyes proyectos reales y pierdes el miedo al código.

> **La metáfora que guía todo el curso:** 🦴 HTML es el **esqueleto** · 👕 CSS es la **ropa** · 🤸 JavaScript es el **movimiento**.

|Este curso **NO** busca|Este curso **SÍ** busca|
|---|---|
|Memorizar etiquetas|Aprender haciendo|
|Teoría infinita|Entender cómo funciona la web|
|Ser una enciclopedia de HTML|Construir proyectos reales|

---

## 🎯 Al terminar, sabrás

- Comprender cómo funciona una página web por dentro.
- Crear páginas HTML modernas y **semánticas**.
- Construir sitios **accesibles** y optimizados.
- Aplicar buenas prácticas profesionales y **SEO básico**.
- Publicar tus proyectos reales en Internet.

## 🧠 Cómo aprender sin frustrarse

> Nadie memoriza HTML completo. **Googlear es normal**, equivocarse es parte del proceso, y la práctica vale más que la teoría.

Tres ideas que repetimos a lo largo del curso:

- 👂 **Escuchar un lector de pantalla** hace que entiendas la accesibilidad al instante.
- 🔍 **Inspeccionar sitios reales** (YouTube, Google) motiva muchísimo y enseña cómo trabajan los profesionales.
- 🛠️ **Equivocarte y corregir** en DevTools es la forma más rápida de aprender.
